# Tooth Fairy Dentistry: frontend

The React app for the dental clinic. The [main README](../README.md) has the
screenshots, demo logins, features and full setup.

| Command | What it does |
|---|---|
| `npm run dev` | app on http://localhost:5173 (the backend must run on port 3000) |
| `npm run build` | production build in `dist/`, which Express serves in production |
| `npm run lint` | ESLint |
| `npm run test:e2e` | Playwright end-to-end tests (starts both servers if needed) |
| `npm run screenshots` | retakes the README screenshots into `docs/screenshots/` |
